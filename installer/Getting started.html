Switch2NativeControllerDriver

Your controllers. Native Windows input.

Connect your first controller

Bluetooth

  1. Hold the controller’s small SYNC button until its LEDs cycle.
  2. Open Windows Bluetooth settings → Add device → Bluetooth.
  3. Select Pro Controller, Joy-Con 2 (L), or Joy-Con 2 (R).
  4. If it says Not connected after pairing, press a normal button once.

USB

Connect a Switch 2 Pro Controller directly to your PC with a data-capable USB cable.

Its player LED settles and the app’s tray icon appears when connected.

Joy-Con 2 currently uses Bluetooth only.

Make it yours

Right-click the tray icon for Settings, joystick dead zones, gyro mouse speed, live stick plots and rotating controller models with button highlights. Each physical controller keeps its own settings.

When a second Joy-Con connects, choose one combined controller or two separate controllers. Separate controllers are held sideways, with SL/SR as shoulders. The tray closes after the last controller disconnects; the background manager remains ready for the next connection.

The right Joy-Con takes mouse priority. The left becomes the mouse only when no right is connected. Optical mode requires surface contact; gyro mode follows wrist rotation.

Updates and removal

Run a newer official setup to update. Close games and controller tools first. Setup preserves profiles and Windows pairings. Re-running the same version refreshes setup and documentation, rather than forcing a driver replacement.

To remove the driver, use Windows Settings → Apps → Installed apps → Switch2NativeControllerDriver → Uninstall. Profiles, pairings, logs and recovery backups may remain. Never delete the installation record before uninstalling.

Development signing

This preview uses a temporary project certificate and is not Microsoft-certified. Windows or your organization’s policy may block it. Do not disable Secure Boot, Memory Integrity, SmartScreen or driver-signing protections to bypass a failure. A normal production release needs a production signing process.
