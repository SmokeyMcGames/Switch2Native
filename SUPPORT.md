# Support

Start with [installation](docs/INSTALLATION.md), [controls](docs/CONTROLS.md), [Settings](SETTINGS.md) and [known limits](docs/VALIDATION.md).

Use [GitHub issues](https://github.com/SmokeyMcGames/Switch2Native/issues/new/choose) for bugs and focused requests. Support is volunteer-based without guaranteed response time.

Include version/commit, Windows build, controller/firmware if known, Bluetooth adapter, transport/mode, reproduction and expected/actual behavior. Mention competing controller software. Share the smallest relevant redacted excerpt, not a full capture archive.

Never post Bluetooth addresses, factory serials, keys or personal paths. [Report vulnerabilities privately](SECURITY.md).
