# Code of conduct

Everyone is welcome to participate respectfully.

- Discuss code and evidence; avoid personal attacks.
- Do not harass, threaten, discriminate or publish private information.
- Respect different experience levels; give actionable feedback and accept corrections.
- Keep reports relevant and redact hardware/account details.
- Do not post malicious attachments, credentials or public exploit details.

Maintainers may remove harmful content, close disruptive threads or restrict participation in proportion to conduct and impact. This applies to the repository and project-managed discussion spaces.

Report concerns through a private contact listed on the maintainer's GitHub profile. If unavailable, request one without exposing sensitive details. Never disclose another person's private information in a public report.

This project-specific policy does not incorporate another project's code-of-conduct text.
