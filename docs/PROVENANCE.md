## Historical Python references and license caveat

Its LICENSE at revision 4643a9b5f507e478abcc0eff6280363ac399ebc7 explicitly limits MIT to that author's additions and says the Nadeflore/TommyWabg ancestors lacked explicit licenses. **That MIT notice cannot grant permission for someone else's unlicensed code.** Attribution alone is not permission.

The reviewed overlap concerns controller packet fields, GATT UUIDs, command headers, button bits and calibration layouts. Switch2NativeControllerDriver's native C++ transport/parser uses its own data structures, cancellation, validation and state handling; the Python application, GUI, assets, runtime and virtual-controller bridge are not included. The historical notice is preserved transparently, not treated as blanket permission for those ancestors. No unlicensed Python implementation is vendored in this repository.

## Protocol facts and independently implemented components

Packet/command/identity information was cross-checked against [ndeadly's controller research](https://github.com/ndeadly/switch2_controller_research), including command headers, report layouts and factory memory. Those documents are linked rather than copied. Controller protocol constants are distinguished from upstream application source.

Packed motion decoding was reconstructed from hardware observations with guidance from Nintendo's [Input Processing Using Encoding and Decoding publication](https://patents.justia.com/patent/20260295396). No third-party decoder library is bundled. This reference is **not** a patent license or a freedom-to-operate conclusion.

Gyro mouse behavior was informed by public air-mouse documentation; no TDK, Nordic or Infineon proprietary motion library is included. Relative movement, calibration, compensation and click stabilization are implemented in project C++.

## Toolchain and assets

Windows SDK/WDK and Visual Studio are developer build tools under Microsoft's terms; end users do not need them to run the offline installer. The driver uses HID/XInput components and system libraries included with Windows 11. Microsoft toolchain binaries, headers and installers are not vendored here, and no separate Visual C++ runtime installation is required.

The tray PNG was supplied by the maintainer; its ICO is generated by tools/Build-Icon.ps1. The README vector banner is project artwork, and the model illustration is output from the project's renderer. Licensing these contributions does not grant rights in third-party trademarks.
